The visual editor of Blocky: a fast Preact canvas builder with closed-set controls.

== Description ==

Blocky Builder is the visual editor for Blocky Core: drag-and-drop canvas, inspector with
content/style/layout/animations panels, starter-friendly closed-set controls and an
"Edit with Blocky" button in the WordPress editor that converts any page non-destructively.

Requires the Blocky Core plugin.

== Installation ==

1. Upload the blocky-builder folder to /wp-content/plugins/.
2. Activate it together with Blocky Core.

== Frequently Asked Questions ==

= Can I go back to the block editor? =
Yes. Conversion never modifies post_content.
