The visual editor of GG: a fast Preact canvas builder with closed-set controls.

== Description ==

GG-Builder is the visual editor for GG Engine: drag-and-drop canvas, inspector with
content/style/layout/animations panels, starter-friendly closed-set controls and an
"Edit with GG" button in the WordPress editor that converts any page non-destructively.

Requires the GG Engine plugin.

== Installation ==

1. Upload the blocky-builder folder to /wp-content/plugins/.
2. Activate it together with GG Engine.

== Frequently Asked Questions ==

= Can I go back to the block editor? =
Yes. Conversion never modifies post_content.
